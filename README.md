# FinDesk

Projeto pessoal de finanças e investimentos para Windows, previsto em Angular, Electron e TypeScript.

Neste momento, o diretório contém a **revisão e a consolidação documental**. A aplicação ainda não foi criada; não há comandos de instalação, execução, build ou testes de software disponíveis.

Leia nesta ordem:

1. [Visão consolidada e limites](PROJECT_BRIEF.md).
2. [Estado real e continuidade](PROJECT_STATUS.md).
3. [Instruções operacionais](AGENTS.md).
4. [Revisão, precedência e fontes originais](docs/REVIEW.md).

Os originais estão preservados em `docs/references/`. Propostas, pesquisas pendentes e decisões confirmadas são identificadas separadamente. O primeiro conjunto de desenvolvimento previsto é uma base mínima da aplicação e propostas de identidade; a etapa 0 completa será dividida em pequenas entregas.
